# Changelog

English first, German below. / Englisch zuerst, Deutsch darunter.

## 1.1.0
Revised according to the Grybyx accessibility mod guide: Control stops speech everywhere, new key layout (F2, F5, F6, F9, F10, F11), mod menu with submenus, discard, donation and Grybyx links, sound preview, projectile warning, quieter fight start, robust round result, language-change announcement, separate ducking for sounds, own log, voice list and data collector. First public release.

## 1.0.7
Voice selection per language, invincibility and big-damage sounds.

## 1.0.6
Announcements in the game language; own side detected from the AI-controlled fighter; no counter/punish/reversal announcements.

## 1.0.5
Voice by game language, no chat/superchat announcements, pause detection fixed, collab readiness corrected.

## 1.0.4
Audio ducking; a newly selected menu item always interrupts the previous announcement.

## 1.0.3
Distinct sounds per cue, silence in pause, switch values read directly.

## 1.0.2
32-bit SAPI speech helper; installer also fetches the unstripped Unity libraries.

## 1.0.0 – 1.0.1
First versions: spoken menus, character select, opponent locator, health warnings.
